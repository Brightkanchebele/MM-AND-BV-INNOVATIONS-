START
1. Extract this ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. Use Settings & Data to set the business name, currency, owner WhatsApp number, team WhatsApp numbers, and low-stock threshold.
4. Back up records regularly using Settings & Data > Export full backup.

FEATURES
- Stock entry for each jersey/size/branch, including quantities.
- Record a sale and select the exact stock item at the matching branch; quantity is deducted automatically. When it reaches zero, the stock line is removed.
- Low-stock flags based on the configurable threshold.
- Kabwe and Lusaka stock comparison.
- Printable receipts and WhatsApp sharing to customer, owner, or team.
- Selected-month sales report and full management report exports.
- Transactions, inventory, lay-by, team, backups and CSV exports.

IMPORTANT LIMITATIONS
This remains a front-end prototype. Data is stored in the browser on this device and is not synchronised between phones/computers or branches. WhatsApp sharing opens a pre-filled message for the chosen recipient; it does not silently send messages. Printing uses the browser print dialog. For live shared stock across Lusaka and Kabwe and automatic WhatsApp notifications, connect a cloud database, authentication and an approved WhatsApp Business messaging provider. Keep backups and physically count/reconcile all stock before relying on balances.

EDITING AND DELETING
The Transactions, Inventory & Stock, Lay-by Accounts, and Team Management sections now provide Edit and Delete actions. Changes are saved to this browser's local records. Editing an old transaction does not automatically reverse/reapply stock movements; adjust inventory separately if needed. Deleting a transaction also does not automatically restore previously deducted stock.
- Add a stock photo for each jersey/item and label it First Class or Second Class. Pictures and class labels appear in the stock register; you can replace or remove pictures when editing.
- Add a profile picture for each team member. Team photos appear on their team cards and can be replaced or removed when editing.
- Images are resized/compressed in the browser before saving. Use smaller image files and make regular backups because browser storage has limits.
